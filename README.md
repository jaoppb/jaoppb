### 👨‍💻 About Me

I am a Software Engineering student at **PUC Minas** (Belo Horizonte, Brazil)
passionate about engineering robust solutions across the entire software
spectrum. As a polyglot developer, I bridge low-level systems programming with
scalable web and mobile applications:

- 🦀 **Systems & Tooling:** Building fast, low-overhead software in Rust and C,
  specializing in networking, DNS resolvers, and Wayland/Linux desktop
  environments.
- 🌐 **Backend & Architecture:** Designing resilient APIs and distributed
  architectures with TypeScript, Python, and Go.
- 📱 **Mobile & Web:** Crafting cross-platform applications with Flutter/Dart
  and reactive modern web interfaces.
